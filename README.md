<h1>SpiceWorks Ticketing System</h1>
This tutorial outlines the process of setting up a ticketing system and managing IT Support
tickets from our lab environment to simulate platforms like ServiceNow or Jira.<br />


<h2>Environments and Technologies Used</h2>

- Microsoft Azure
- Windows Environment
- SpiceWorks

  
<h2>Operating Systems Used </h2>

- Windows 11
